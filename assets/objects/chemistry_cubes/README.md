# Chemistry Cubes

RoboLab periodic-table cubes with black top-face label geometry and category-tinted porcelain bodies.

- Cube size: 5.0 cm
- Edge bevel/chamfer: 4.0 mm
- Body material: uploaded `Porcelain001_1K-PNG` PBR maps, copied under `textures/` for easy replacement
- Category coding: porcelain body tint uses periodic-table category colors; labels are black for contrast
- Class: `chemistry_cube`
- Dataset: `chemistry_cubes`
- Collision metadata: dynamic rigid body with convex-hull mesh collision
